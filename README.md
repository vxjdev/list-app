# list-app

Shopping list AI application. Add grocery items and compare estimated Woolworths vs Coles prices using the Gemini API.

## Setup

```bash
npm install
npm run dev
```

You'll need a Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey). Enter it in the app's API key field — it's stored in your browser's local storage and never leaves your machine except to call the Gemini API directly.
